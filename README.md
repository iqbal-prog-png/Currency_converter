# 💱 Currency Converter Web App

A responsive _Currency Converter_ web application built using _HTML, CSS, and JavaScript_.  
It allows users to convert between _all world currencies_ with real-time exchange rates.

## 📌 Features

- 🌍 Supports _all global currencies_
- 🔁 Convert between any two currencies
- 🇺🇸 Country flags update automatically
- 📱 Fully _mobile responsive_
- ⚡ Fast & lightweight (no backend)
- 🆓 Uses free public currency API (no API key required)

---

## Tech Stack

- _HTML5_ – Structure
- _CSS3_ – Styling & responsiveness
- _JavaScript (ES6)_ – Logic & API handling
- _Currency API_ – Exchange rates
- _Netlify_ – Deployment
